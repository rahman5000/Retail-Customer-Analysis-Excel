# Retail Customer Analysis – Excel

## Project Overview
This project focuses on analyzing retail customer data using Microsoft Excel to understand customer information and identify useful business insights.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Excel Formulas
- Charts and Data Visualization

## Project Objectives
- Understand customer data.
- Organize and clean raw data.
- Analyze customer-related information.
- Identify useful patterns and trends.
- Present insights through Excel reports and visualizations.

## Skills Demonstrated
- Data Cleaning and Formatting
- Data Analysis
- Pivot Table Analysis
- Excel Formulas
- Data Visualization
- Business Reporting

## Project File
`Retail_Customer_Analysis_Excel.xlsx` – Excel workbook containing the retail customer analysis.

## How to Use
1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Explore the worksheets, analysis, and visualizations.
